Represents a given latitude and longitude coordinate, measured in degrees, and optionally an altitude in metres.

The coordinates are based on the <a href="https://en.wikipedia.org/wiki/World_Geodetic_System#WGS84" target="_blank">WGS84 (EPSG:4326) standard</a>.
