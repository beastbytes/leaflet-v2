# Installation

## Requirements

**LeafletV2** requires:

* PHP 8.2 or higher.
* Leaflet mapping library Version 2.

## LeafletV2

Install **LeafletV2** using [Composer](https://getcomposer.org/).

Either using the command-line:
```shell
composer require beastbytes/leaflet-v2
```

or add
```json
"beastbytes/leaflet-v2": "{{vesrion constraint}}"
```

to the `require` section of the project `composer.json`.

## Leaflet Mapping Library

Download the Leaflet mapping library and place it in a publicly accessible directory - 
this documentation assumes that Leaflet is placed in the `/leaflet` directory.
