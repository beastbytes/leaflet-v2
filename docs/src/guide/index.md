# Leaflet V2

**LeafletV2** allows [Leaflet](https://leafletjs.com/) Version 2 maps to be created in PHP.

<!--@include: ../index.md{23,}-->

## Features

* Leaflet Version 2 support.
* Additional map manipulation supported.
* [Leaflet plugins](https://leafletjs.com/plugins.html) supported. (Plugins _must_ be compatible with Leaflet Version 2)
* Fluent API for setting options.
* No dependencies (other than PHP and Leaflet).
